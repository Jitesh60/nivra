# Content rating

**Play (IARC questionnaire):** category *Social / communication? No* → choose **"All other app types"**.

| Question | Answer |
|---|---|
| Violence, sexuality, language, controlled substances, gambling | No |
| Does the app let users interact or exchange content? | **Yes** (chat between borrower and lender) |
| Does the app share the user's location with other users? | **Yes, approximately** (the area of a listing; the exact address only after a booking is paid) |
| Can users buy digital goods? | No (payments are for renting physical items) |
| Is it a web browser or search engine? | No |

Expected result: IARC 12+ / PEGI 12 (because of user interaction), "Users Interact".

**App Store age rating:** all content categories "None"; "Unrestricted web access": No; "User-generated content": the app has reporting and blocking (Report and Block in chat, Report on listings and bookings), which Apple requires. Result: **12+**.

**Target audience (Play):** 18 and over. Accounts need a phone number and payments; the terms require users to be 18+.
