# App Store Connect: App Privacy ("nutrition label")

**Do you or your third-party partners collect data from this app?** Yes.
**Tracking:** No. Nivra doesn't track people across other companies' apps or websites, and has no advertising SDKs. (No App Tracking Transparency prompt is needed.)

## Data linked to the user

| Data type | Purposes |
|---|---|
| Contact info · Name | App functionality |
| Contact info · Email address | App functionality, customer support |
| Contact info · Phone number | App functionality |
| Contact info · Physical address | App functionality (lenders' pickup address) |
| Financial info · Other financial info | App functionality (lenders' payout bank details, via Razorpay) |
| Location · Precise location | App functionality (only when a lender pins a pickup point) |
| Location · Coarse location | App functionality (what's near you) |
| Sensitive info | App functionality (government ID photos, only if the user adds them) |
| User content · Photos | App functionality |
| User content · Other user content | App functionality (chat messages, reviews, condition notes) |
| Purchases · Purchase history | App functionality |
| Identifiers · User ID | App functionality |
| Identifiers · Device ID | App functionality (push notifications) |
| Usage data · Product interaction | Analytics (listing views, favourites) |

## Data not linked to the user

| Data type | Purposes |
|---|---|
| Diagnostics · Crash data | App functionality (Sentry, only with crash reporting on; scrubbed of phone numbers, emails and codes) |

Payment card and UPI details are entered in Razorpay's checkout and never reach Nivra, so they're not declared.
