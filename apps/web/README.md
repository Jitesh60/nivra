# @sajha/web

Sajha marketing website (Next.js, Tailwind v4).

```bash
pnpm dev        # http://localhost:3002
```

Phase 0 ships a placeholder page using the shared brand tokens. Phase 1d builds the full landing page with shaders.com, React Bits and uiverse.io effects and the waitlist form (see [docs/PHASES.md](../../docs/PHASES.md)).
